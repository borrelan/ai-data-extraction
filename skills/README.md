# Verified user skill bundle

This directory contains portable snapshots of the four user skills that are
directly relevant to this corpus and to disciplined engineering work:

- `core-principles`: architecture-first ownership, evidence, and closure gates
- `contract-enforcement`: typed boundary and single-funnel contracts
- `systematic-debugging`: reproduction, first-divergence, and failure-plane analysis
- `code-indexer-ops`: qualified Code Indexer use with lifecycle/provenance gates

The snapshots were synchronized from the local user skill profile under
`~/.codex/skills/personal/` on 2026-09-17 and their SHA-256 identities were
verified against the source files. They are instruction artifacts, not
conversation examples. Refresh them from the user profile when the source skills
change; do not silently treat a generated skill as an authoritative replacement.

No additional repository-specific `SKILL.md` files were found during this
audit. The other personal skills remain available from the user profile and
should be imported deliberately when a task needs their external tool or
product-specific scope.
